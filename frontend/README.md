# Smart Clinic — React frontend

React + TypeScript + Vite, подключённые к существующим Spring REST-контроллерам.

## Запуск

Требуется Node.js 22.12+ (или совместимая более новая версия). Запустите backend с PostgreSQL, MongoDB и `JWT_SECRET`, как описано в корневом README, затем:

```bash
cd frontend
npm ci
npm run dev
```

Vite выводит адрес интерфейса (обычно http://localhost:5173). Запросы `/api/*` проксируются на `http://localhost:8080/*`. Для другого адреса backend:

```bash
BACKEND_URL=http://localhost:9090 npm run dev
```

Используется стандартное значение backend `api.path=/`.

## Возможности

- Пациент: регистрация, вход, поиск врачей по имени, специальности и времени суток, доступные интервалы на дату, запись, перенос и отмена будущего приёма, фильтрация записей по статусу и имени врача.
- Администратор: вход, создание, редактирование и удаление врачей. Удаление подтверждается, поскольку сервер удаляет также приёмы этого врача. При редактировании API требует новый пароль.
- Врач: вход, расписание на дату, поиск пациента, его контакты и история приёмов у текущего врача, просмотр и создание рецепта. Создание рецепта завершает приём.
- Ошибки сервера, состояния загрузки, пустые результаты и блокировка повторного отправления форм.

Сессия хранится только в памяти: после перезагрузки страницы нужно войти снова. Истёкший токен возвращает пользователя на экран входа. Права доступа проверяет backend. Просмотр рецептов пациентом и общий список пациентов для администратора не доступны в текущем API и не представлены в интерфейсе.

## Сборка

```bash
npm run build
npm run preview
```

Сборка создаётся в `dist/`. Локальный preview также использует прокси. При production-размещении настройте reverse proxy: `/api/*` → backend с удалением `/api`; остальные запросы обслуживает frontend. Vite-прокси не входит в статическую сборку. Старые страницы Spring/Thymeleaf сохранены.
