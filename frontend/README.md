# Smart Clinic — React frontend

Стартовая панель на React + TypeScript + Vite. Есть переключение предпросмотра роли (администратор / врач) и разделов. API пока не подключён, данные пациентов не загружаются, авторизация не реализована. Переключатель роли не предоставляет серверные права доступа.

## Запуск

Используйте Node.js 22.12+ (или совместимую более новую версию).

```bash
cd frontend
npm ci
npm run dev
```

Откройте URL, выведенный Vite в терминале.

```bash
npm run build
npm run lint
npm run preview
```

Сборка создаётся в `dist/`. `preview` предназначен для локальной проверки сборки.

## Следующие этапы

Реализовать REST-контроллеры и сервисы в `../app`, согласовать маршруты и DTO, добавить вход и серверную проверку ролей, затем подключить разделы к API. Для production необходимо настроить размещение frontend и доступ к backend. Старые Thymeleaf-шаблоны пока сохранены в backend.

Целевая архитектура описана в [schema-architecture.md](../schema-architecture.md).
